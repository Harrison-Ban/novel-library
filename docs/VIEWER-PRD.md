# 소설서재 – 텍스트 뷰어 추가 기능 PRD

## 1. 목적
현재 txt 파일 열기 기능이 구현되어 있음.
이를 프로그램 안에서 가볍고 편하게 소설을 읽을 수 있는 뷰어로 확장한다.
기존 기능(분류, 폴더 연동, 파일 이동/삭제, doc→txt 변환)은 그대로 유지해야 한다.

## 2. 핵심 기능 (필수)
1. 서재 목록에서 파일을 누르면 뷰어 화면으로 열림
2. 읽기 전용: 뷰어에서는 본문 편집 불가 (수정, 입력, 삭제 모두 막을 것. 복사는 허용)
3. 글자 크기 조절 (크게/작게 버튼)
4. 줄 간격 조절
5. 다크모드 / 라이트모드 전환
6. 마지막으로 읽은 위치 자동 저장 → 다시 열면 그 위치부터 이어 읽기
7. 읽은 진행률(%) 표시
8. 단어 찾기
   - 검색어 입력 시 본문 내 일치 항목 강조 표시
   - 총 몇 건인지 표시 (예: 3/15)
   - 이전/다음 버튼으로 이동
9. 책갈피
   - 현재 위치에 책갈피 여러 개 추가
   - 책갈피 목록에서 선택하면 해당 위치로 이동
   - 책갈피 삭제 가능
   - 책갈피마다 앞부분 몇 글자 또는 진행률 표시로 구분
10. 한글 인코딩 자동 처리 (UTF-8, CP949/EUC-KR 모두 깨지지 않게)
11. 큰 파일(수 MB 이상)도 느려지지 않게 열기

## 3. 연동 조건
- 휴대폰과 PC 어느 쪽에서 읽어도 읽은 위치, 책갈피, 설정이 함께 업데이트되어야 함
- 저장 방식은 기존 서재 데이터 저장 방식과 맞출 것
- (결정) 글자 크기·여백은 기기별, 줄 간격·테마·넘기기 방식은 공유

## 4. 화면 조작
- 휴대폰: 화면 탭 또는 스와이프로 넘기기
- PC: 방향키, PageUp/PageDown, 스페이스로 넘기기, Ctrl+F로 찾기
- 뷰어에서 서재 목록으로 돌아가기 버튼

## 5. 있으면 좋은 기능 (선택, 2단계)
- 글꼴 선택

## 6. 주의사항
- 실제 소설 txt 본문은 열람하지 말 것. 테스트는 직접 만든 샘플 txt 파일로 진행
- 기존 코드를 크게 바꿔야 하면 먼저 알려주고 승인 후 진행

## 7. 진행 방식
- 바로 코드 작성하지 말고, 기존 구조를 확인한 뒤 어디에 어떻게 붙일지 계획부터 보여줄 것
- 계획 승인 후 2번 필수 기능부터 구현
- 완료 후 테스트 방법을 쉽게 설명해줄 것
